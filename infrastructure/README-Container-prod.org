* Produktion
- Es werden keine Demodaten importiert: =entrypoint.sh= seedet sie nur bei
  =FLASK_DEBUG=1=, und =compose.yaml= setzt =FLASK_DEBUG=0=.
- Es muss ein erster Benutzer mit Reviewer-Rechten angelegt werden.

** Ersten Reviewer anlegen

Die =user_id= ist zugleich die Login-URL =/reviewer/<user_id>=, also
zufällig erzeugen und nicht erraten lassen:

#+begin_src bash

  python3 -c "import secrets; print(secrets.token_hex(20))"
  just prod-db

#+end_src

#+begin_src sql

  INSERT INTO users (user_id, user_name, user_rolle, user_kontakt)
  VALUES ('<zufällige id>', 'Reviewer 1', '9', 'reviewer@mantis.org');

#+end_src
