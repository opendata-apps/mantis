* Übersicht

|-----------------------+-----------------------------------|
| Datei                 | Zweck                             |
|-----------------------+-----------------------------------|
| compose.yaml          | Gemeinsame Basis: Flask + DB      |
| compose.override.yaml | Dev, wird automatisch geladen:    |
|                       | Hot-Reload, Vite, DB-Port         |
| compose.prod.yaml     | Prod, muss explizit angegeben     |
|                       | werden: restart, Loopback-Port    |
| Dockerfile            | Python-Image + App-Dependencies   |
|-----------------------+-----------------------------------|

Ein nacktes =podman-compose up= in diesem Verzeichnis startet die
Entwicklungsumgebung. Produktion erfordert die explizite Angabe von
=compose.prod.yaml=.

* Arbeiten mit Podman/Podman-Compose
** Stoppen
*** Anhalten: Stoppen 
#+begin_src bash

  cd infrastructure
  # podman-compose down
  podman-compose down

  # if production

  podman-compose -f compose.yaml -f compose.prod.yaml down
  
#+end_src

*** Anhalten: Stoppen und Volumes löschen
Falls alles frisch aufzusetzen ist:

#+begin_src bash

  podman-compose down -v

#+end_src

(-v entfernt auch die Volumes, also deine PostgreSQL-Daten!)
** Löschen: Altes Image

#+begin_src bash
  
  podman images
  podman image rm <image_name_or_id>
    
#+end_src
** Löschen: <none> - Images
#+begin_src bash
  podman image ls -a | grep '<none>' | awk '{print $3}' | xargs podman rmi -f
#+end_src
** Löschen: Tailwind-Image

#+begin_src bash

  podman volume ls                  # Liste aller Volumes
  podman volume rm tailwind_build

  # Danach Dev-Container neu starten:

  podman-compose up
  
#+end_src

** Neu bauen: Podman-Compose


Alles neu bauen ...

#+begin_src bash

  podman-compose build --no-cache
    
#+end_src

** Starten:
*** Podman-Compose -- development

#+begin_src bash
    # 1. Dependencies installieren (einmalig / CI)
    bun install

  # 2. Tailwind CSS im Watch-Mode starten
    bun run watch:css
  
    # 3. Container starten
    cd infrastructure
    podman-compose up

#+end_src

*** Podman-Compose -- production

#+begin_src bash

  # 1. Fertige CSS bauen
  bun run build:css

  # 2. Docker Image bauen
  podman build -t mantis_web ..

  # 3. Container starten
  podman-compose -f compose.yaml -f compose.prod.yaml up -d
  podman-compose -f compose.yaml -f compose.prod.yaml up -d --build

#+end_src
